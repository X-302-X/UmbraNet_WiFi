# UmbraNet WiFi

UmbraNet — сетевой контроллер. Активный DPI и исполнение оригинальной Uz1
пока намеренно заблокированы: локальные модели и диагностика не доказывают
безопасный обход DPI или работу YouTube.

## WinDivert и ручная проверка

WinDivert — общая служба Windows, которую могут использовать другие программы.
Перед ручной проверкой сохраните работу и закройте Zapret и другие программы,
использующие WinDivert. Проверка запускается только по подтверждению пользователя
кнопкой «Проверить возврат пакетов» внизу журнала. Это активный перехват IPv4
localhost на временном порту с передачей исходных пакетов и адресов обратно в API.
WinDivert может пересчитать checksum при снятых флагах; это не гарантия побайтной
неизменности пакета на выходе. Другая локальная программа может подключиться
к тому же порту; возможна потеря пакетов. Проверка
не запускает DPI, не проверяет внешние сайты и не останавливает общую службу.
Результат об ошибке или зависании не подтверждает закрытие/выгрузку драйвера.
Не останавливайте службу, пока она может использоваться другой программой.

## Сборка Windows

GitHub Actions сначала проверяет SHA-256 пользовательского `strtegs_Uz/uz1.json`,
собирает отдельный helper и включает его в установщик, но не выполняет живой тест.
Файл `uz1.json` должен совпадать с оригиналом побайтно, включая окончания строк;
загрузите его в репозиторий как файл, не через текстовый редактор GitHub.
`.gitattributes` запрещает автоматическую конвертацию этого файла при checkout.
При несовпадении Actions сообщает ожидаемый и фактический хеши; проверку не обходят.

Для локальной Windows x64 release-сборки перед Tauri необходимо создать helper:

```powershell
cargo build --locked --release --manifest-path core/dpi/Cargo.toml --target x86_64-pc-windows-msvc --target-dir core/dpi/target --features loopback-probe --example loopback_probe
npx --yes --package=@tauri-apps/cli@2.12.4 tauri build --target x86_64-pc-windows-msvc --bundles nsis -- --locked
```

Обе команды выполняются из корня репозитория. Установщик кладёт helper рядом с
`WinDivert.dll` и `WinDivert64.sys`; это отдельный процесс, не активный DPI.
